# STOPA — FEATURE REGISTRY (registr funkcí)

Rozlišení stavů: IMPLEMENTED ≠ TESTED ≠ VERIFIED.
- **impl:** implementováno | **test:** testováno (unit/integration) | **verif:** nezávisle ověřeno (plná sada + ruff + commit)
